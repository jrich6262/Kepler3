This repository contains Python programs that demonstrate Kepler's Third Law for the major bodies and Saturn's moons. Data is taken from NASA's JPL Horizons System.

* Report.pdf: Technical report on the project.

* main.txt: LaTeX code for the report.

* src:

  * major_bodies.py: Analyzes the 8 planets.

  * saturns_moons.py: Analyzes 8 of Saturn's moons.
 
* output: Stores the generated graphs.
