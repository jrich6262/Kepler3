## Kepler3

**Overview**

This repository contains Python scripts that demonstrate Kepler's Third Law of planetary motion. The program calculates the relationship between orbital period and semi-major axis for both the major planets of the Solar System and the moons of Saturn by using data queried from NASA's JPL Horizons System.

**Repository Structure**

* `src/`: Contains the primary analysis scripts.
  * `major_bodies_2.py`: Analyzes the major bodies.
  * `saturns_moons.py`: Analyzes 8 of Saturn's moons.
* `output/`: Stores the generated graphs (`MAJOR_BODIES.pdf` and `SATURNS_MOONS.pdf`).
